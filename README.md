# Pradip Ludo King

A simple local multiplayer Ludo-style Android app starter project.

## Build an APK for free with GitHub Actions
1. Create a GitHub account and a new repository.
2. Upload all files in this ZIP to the repository (keep the `.github/workflows/build-apk.yml` path).
3. Open the repository's **Actions** tab.
4. Select **Build Pradip Ludo King APK** and press **Run workflow** (or push to `main`).
5. When the workflow finishes, open the run and download the `Pradip-Ludo-King-APK` artifact.
6. Extract the downloaded artifact ZIP to get `app-debug.apk`.

This is a debug APK for testing, not a Play Store release.

## Notes
- Designed for local play on one phone.
- This is an initial playable prototype. Rules and board layout are simplified and should be tested before public release.
